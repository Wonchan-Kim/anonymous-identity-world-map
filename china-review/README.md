# China Android Wi-Fi peer review

Published entry point:
[China review workbench](https://wonchan-kim.github.io/anonymous-identity-world-map/china-review/).

This buildless site contains the 12 November 2026 USRA China research snapshot:
933 frozen-roster institutions, 180 manual Android EAP procedures from 150
universities, 96 institutions with unresolved selected source contents, two
separate EAP onboarding procedures, and 18 Android connectivity clients whose
EAP function is unverified. These groups overlap and use different count units.

The original research classifications are read-only in the interface. Reviewer
changes, quoted evidence, Android-context reasoning, source URLs, and additional
network routes are independent proposals. They are saved in browser localStorage
for this exact snapshot. There is no shared comments server or account system.

Reviewers should download **JSON** after working and return it to the research
team. JSON preserves drafts and completed reviews and can be imported without
overwriting the original dataset or the current reviewer's edits. CSV is a
human-readable companion, not the import format. Different snapshot versions
are rejected rather than silently matched. Subsequent revisions of the same
imported opinion update that opinion; independent reviewers remain separate.

`data.json` contains only the selected research findings and public URLs, with
no keys or local file paths. `assets/` contains unchanged, deduplicated figures
that were visually reviewed in the source research; whole PDFs, Word documents,
videos and raw HTML captures are not republished here. Each manual guide retains
its Android basis, identity evidence, original source and available version
limits. A blank example field does not imply an explicit instruction to leave it
blank. Unread candidate guides never become `not_mentioned` automatically.

Serve through HTTP/HTTPS; opening the HTML using `file://` cannot fetch the
snapshot consistently. The main world map and SecureW2 page are independent.
