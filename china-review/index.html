REVIEW PROTOCOL

先确认配置范围，再判断匿名身份。

研究对象是高校官方发布的 Android 手动 EAP / 802.1X 配置指南。即使没有写 Android，只要实际界面、机型或操作上下文足够明确，也可以纳入；请记录判断依据。

  1. 打开官方原文区分学校 Wi-Fi 与 eduroam，记录页面或手册版本。需要查看的截图、扫描页或视频也属于证据。
  2. 核对 Android 与 EAP查找 EAP、PEAP、802.1X、Identity 等参数；网页认证 Portal、共享密码 PSK 和其他非 EAP 连接不纳入匿名身份分类。
  3. 按明确指示分类未填写的示例框不等于要求留空。图片必须实际查看；没有打开的材料保留“未核实”。
  4. 记录并导出意见填写建议、官方链接和关键原文。点击“完成本项复核”后，下载 JSON 发给研究团队；也可以导出 CSV 阅读版。
