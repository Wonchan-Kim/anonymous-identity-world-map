# University Wi-Fi Anonymous Identity Globe

Interactive country-level visualization of anonymous-identity guidance for
eduroam and institution-operated school Wi-Fi networks.

The public bundle contains only the standalone visualization and aggregated
country-level values. It does not contain the underlying manual-review CSVs,
crawler outputs, credentials, or API keys.

## GitHub Pages

The site entry point is `index.html`. In the repository settings, enable GitHub
Pages from the `main` branch and the repository root.
