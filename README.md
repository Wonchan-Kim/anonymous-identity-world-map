# University Wi-Fi Anonymous Identity Globe

Interactive country-level visualization of anonymous-identity guidance for
eduroam and institution-operated school Wi-Fi networks.

The main visualization contains aggregated country-level values. The separate
`china-review/` workbench publishes an allowlisted China research snapshot:
school names, reviewed guide classifications, public source links, research
notes, and the previously inspected configuration figures. It does not publish
raw source captures, manual-review CSVs, credentials, or API keys.

The [China peer-review workbench](https://wonchan-kim.github.io/anonymous-identity-world-map/china-review/)
has a Chinese interface and separates unread source candidates from confirmed
Android EAP procedures. Reviewer input is saved in the reviewer's browser and
must be exported as JSON and returned to the research team; no comments are
uploaded to this repository or automatically merged into research data.

## GitHub Pages

The site entry point is `index.html`. In the repository settings, enable GitHub
Pages from the `main` branch and the repository root.
